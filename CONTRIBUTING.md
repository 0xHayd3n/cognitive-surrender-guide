# Contributing

Corrections should identify the affected guide file, the exact attached manuscript version, source section/PDF page, proposed wording, and any effect on claim/result metadata. Keep reported findings separate from interpretation and preserve all authors' credits.

Do not replace v20260111 with a later manuscript silently. New versions need a documented comparison, updated page map, and clear provenance. Missing appendices may be added to coverage only after verifying the official source/version; link to them rather than republishing their full text.

Preserve uncertainty, denominators, and unresolved reporting discrepancies. Do not invent exclusions, fill absent confidence intervals, infer values from chart pixels without inspection, or label documentation checks as a replication. Original concise explanations are welcome; source PDFs, full text, original figures, private attachment identifiers, and unlicensed assets are not.

Run `python scripts/validate_repository.py` before proposing a change. Inspect modified external links separately. The script checks repository integrity and does not establish scientific validity.
